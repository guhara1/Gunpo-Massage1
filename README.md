# 바로 GO — 군포시 출장마사지·홈타이 안내 사이트

경기도 군포시 전지역 방문 관리(출장마사지·홈타이) 안내용 정적 사이트입니다.
전화예약: **0508-202-4719**

## 구조

- 정적 HTML 사이트 — 어느 호스팅(GitHub Pages, Netlify, 일반 웹서버)에서든 그대로 서빙 가능
- `build.py` + `content/` 패키지에서 페이지를 생성하는 빌드 방식
- 생성물(각 디렉터리의 `index.html`, `sitemap.xml`, `robots.txt`)도 저장소에 포함
- 지역 확장을 고려해 군포 콘텐츠는 `/gyeonggi/gunpo/` 경로 아래에 배치하고, 루트(`/`)는 군포 메인으로 리다이렉트

```
build.py            # 빌드 스크립트 (레이아웃·글자수 검사·sitemap·루트 리다이렉트)
content/
  site.py           # 상호(바로 GO)·전화·BASE_URL·메뉴·텔레그램 링크
  main.py           # 군포시 메인 (+ Organization/WebPage/FAQPage JSON-LD)
  areas.py          # 대표동 7개 (산본·금정·군포·당정·부곡·대야미·송부)
  stations.py       # 역세권: 허브 + 7개 (산본·금정·군포·당정·대야미·수리산·반월 인접)
  area.py           # 생활권: 허브 + 10개
  info.py           # 예약 안내·이용 전 확인사항·홈타이 가이드·고객센터·약관·개인정보
  about.py          # 사이트 소개 (E-E-A-T: Who/How/Why)
assets/             # CSS(프리미엄 팔레트), 모바일 내비 JS
```

## 빌드

```bash
python3 build.py
```

빌드 시 페이지별 본문 글자수 리포트가 출력됩니다.

## SEO 운영 원칙 (빌드에 강제됨)

- 본문 **2,000자 미만 페이지는 자동 `noindex`** 처리되고 sitemap에서 제외
- 대표동은 7개만 — 산본1·2동은 산본동으로, 군포1·2동은 군포동으로 통합 (숫자 행정동 페이지 없음)
- 오금동·수리동·궁내동·광정동·재궁동·둔대동·속달동·도마교동은 단독 페이지 없이 생활권에서 보조 설명
- 역은 역명 1개당 페이지 1개 — 금정역 같은 환승역도 URL 하나, 출구별/노선별 페이지 없음
- 반월역(안산)·명학역(안양)·의왕역(의왕)은 군포 핵심 역세권으로 만들지 않고 인접 생활권으로만 설명
- 메뉴명·URL에 "출장마사지" 반복 없음 — 키워드는 Title/H1/첫 문단에서만 자연스럽게 사용
- 모든 페이지 본문은 페이지별 고유 작성 (지역명만 바꾼 복붙 없음, 도어웨이 방지)

## 배포 전 해야 할 일

1. `content/site.py`의 `BASE_URL`을 실제 도메인으로 변경
2. `python3 build.py` 재실행 (canonical·sitemap·robots.txt에 반영됨)
3. Google Search Console에 `sitemap.xml` 제출
4. (선택) PNG 파비콘/OG 이미지는 `바로 GO` 브랜드로 재생성 권장 — `assets/favicon.svg`는 신규 팔레트 반영 완료
